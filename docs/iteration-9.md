# Итерация 9: итоговая поставка и приёмка

Первая версия функциональной адаптации реализована. Проверенный профиль поставки — Linux/WSL2 x86-64, Python 3.12, CPU. Это не заявление о нативном прогоне Windows или качестве моделей на реальных данных.

Исправления финальной приёмки:

1. requirements переведён на закреплённую CPU-сборку PyTorch с официального индекса: локальной программе не требуется CUDA. Добавлены её транзитивные зависимости и Windows-маркеры, dev/browser-инструменты отделены.
2. Демоданные включены в устанавливаемый пакет. Команда demo экспортирует их в пустой каталог. sync_demo_assets и тест проверяют соответствие каноническим examples. Нет зависимости от соседнего checkout.
3. UI использует пакетный пример и текущую рабочую папку для стандартных каталогов: установленный wheel не пишет в site-packages.
4. Подготовлены wheel/sdist, CI Linux/Windows и воспроизводимые CLI/browser-сценарии. Пути архивных запусков в SQLite записываются в переносимом POSIX-виде.
5. Добавлены архитектура, итоговый отчёт переноса, матрица приёмки и инструкции двух ОС.

Проверено в новом venv без PYTHONPATH/system-site-packages: установка CPU-профиля, pip check, 63 теста, сборка/установка wheel, тесты установленного пакета из другой папки, полный цикл данных/обучения/сохранения/нового процесса/прогноза/обновления/контроля/экспорта. Отдельно настоящим Chromium пройден UI с нативной загрузкой файлов и скачиванием результатов; предыдущие AppTest не выдаются за единственное доказательство браузерного пути.

Ограничения: Windows runtime не проверен, CI пока не запускался; cross-platform pip resolver из Linux не признан эквивалентом Windows. Строгая совместимость окружения сохранённых комплектов остаётся намеренной: ранние экспериментальные модели без torch +cpu требуют своего окружения или нового обучения. Реальная БД и реальные данные не использовались. Условия/логи — acceptance.md.

Все девять итераций разработки по текущему плану выполнены в описанной области. Дальнейшая проверка Windows может выявить платформенные исправления; она не скрывается под словом «готово». Учебные материалы и главы с разработкой/обучением моделей не создавались и остаются отдельным следующим этапом по просьбе пользователя.
