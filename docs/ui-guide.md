# Локальный интерфейс PredictML

## Запуск

После установки зависимостей из README:

```bash
python -m predictml ui
```

Откройте адрес, напечатанный в терминале, по умолчанию http://127.0.0.1:8501. Для другого проекта:

```bash
python -m predictml ui --workspace artifacts/my-work --store artifacts/my-models --port 8502
```

Интерфейс привязан к 127.0.0.1. Сервер запускается в headless-режиме: браузер открывается вручную, сбор usage-статистики отключён. Остановка — Ctrl+C в терминале. Альтернатива из корня репозитория: `python -m streamlit run predictml/ui/app.py --global.developmentMode=false --server.address=127.0.0.1`.

Рабочая папка хранит загруженные таблицы и подготовленные данные. Хранилище моделей содержит SQLite, версии и результаты запусков. Их можно выбрать в боковой панели. Для повторного использования укажите тот же путь к хранилищу; выборы формы не заменяют сохранённые модели.

## Таблица

1. Загрузите CSV/XLSX или включите синтетический пример. Для XLSX выберите лист, проверьте предпросмотр и пропуски.
2. Выберите числовую цель и признаки; остальные столбцы исключаются. В разделе типов явно укажите даты как datetime и идентификаторы категорий как categorical, если требуется. Auto определяет только numeric/categorical на train.
3. Настройте MLP, seed и early stopping. Для временной задачи укажите дату origin, частоту, горизонт, смысл уже подготовленной цели и подтвердите доступность признаков.
4. Нажмите «Обучить и сравнить». Обучаются baseline, linear и MLP; сохраняются версии. График/таблица/метрики и скачивание доступны под формой. Изменение полей формы само по себе не переобучает модель; показанный результат относится к последнему выполненному запуску.

Пустые wMAPE/R² означают неприменимость, не нулевую ошибку. Рекомендуемая модель определяется на validation, не на test.

## Спрос и цена

Можно загрузить набор CSV/JSON с исходными именами или указать локальный каталог. Из сырых notes/services/materials/service_materials CSV кнопка подготовки создаёт полный календарь до даты отсечения; месяц самой даты исключается. materials требует unit/purchase_step. Полученный каталог можно использовать сразу.

Для готового спроса нужны monthly_demand.csv, preparation.json, materials.json, service_materials.json. Для цены — price_analysis.csv. Обучаются MLP и linear; для спроса выбирается горизонт закупки 1–3 месяца. Цена помечена как рекомендация по формуле, не наблюдаемая будущая цена.

## Версии и прогноз

Выберите версию по задаче, алгоритму, цели, дате и короткому ID. Полный ID, родитель, схема, параметры и метрики доступны на экране. Повреждённый/несовместимый комплект не применяется.

Для таблицы загрузите новые признаки без обязательной цели. Для спроса достаточно актуальных JSON-справочников: история уже в версии; при добавлении monthly_demand/preparation действуют правила неизменного исторического префикса. Цена принимает подготовленный CSV. Нажмите «Получить прогноз» и скачайте CSV/XLSX/JSON. Прогноз не обучает модель. При смене входного файла/версии/горизонта прежний прогноз скрывается до нового запуска.

Метрики версии отдельно экспортируются кнопкой в CSV/XLSX.

## Обновление

Выберите родителя, операцию и данные. Продолжение доступно только MLP: сеть и предобработчик остаются прежними, Adam новый. Поле скрытых слоёв применяется только при обучении с нуля. Новая конфигурация JSON необязательна для scratch-retrain таблицы; другую цель/признаки также можно задать через обычный экран обучения новой модели. Результат — новый ID с родителем, прежняя версия сохраняется.

## Контроль

Выберите минимум две совместимые версии и отдельно отложенную размеченную таблицу. Для спроса при необходимости загрузите общую историю. Проверяются provenance, пересечения и временные границы. Старые версии без подтверждаемого происхождения не объявляются независимыми. Сравнение не обучает модели; скачиваются отчёт и прогнозы на одинаковых наблюдениях.

## История

Показывает завершённые/неуспешные/выполняемые запуски, параметры, ошибки и сохранённые результаты. Если процесс действительно остановлен, running-запуск можно явно пометить прерванным. Не отмечайте выполняемую в другом процессе операцию как остановленную.

Загрузка модели после перезапуска восстанавливает сохранённый комплект, а не состояние формы. Загруженные файлы, модели и отчёты остаются в выбранных каталогах. Графический интерфейс вызывает API ядра; CLI по-прежнему доступен.

Большие операции синхронны и показывают индикатор выполнения. Многопользовательские роли, облачное размещение и распределённые задачи не предусмотрены.
