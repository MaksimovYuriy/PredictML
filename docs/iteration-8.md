# Итерация 8: интерфейс Streamlit

Добавлен predictml/ui: шесть экранов обучения по произвольной таблице, спроса/цены, выбора версии и прогноза, обновления, общего контроля и истории. CLI ui запускает локальный сервер без изменения существующих команд. Ядро не импортирует Streamlit.

Интерфейс использует публичные train_file/compare_service/prepare/predict_version/update_version/compare_versions и Store. Присутствуют CSV/XLSX/листы/предпросмотр, выбор цели и признаков, типы и временная постановка, настройки обучения и early stopping, метрики/таблицы/графики, ID/параметры модели, скачивание JSON/CSV/XLSX/HTML. Прогноз и контроль не запускают обучение. Версии восстанавливаются из прежнего хранилища после новой UI-сессии.

Загруженные файлы сохраняются локально, имена ограничены basename; одинаковое содержимое не записывается повторно для одной таблицы. Подготовленные группы сохраняют исходные имена контрактов. Результаты привязаны к выбранной версии и входам; при изменении файла/горизонта прежний прогноз скрывается. Ошибки показываются на экране, стек доступен в закрытом диагностическом разделе. Сохранённые ошибки/результаты видны в истории. Прерывание running-запуска выполняется только при явном указании, что процесс завершён.

Тесты Streamlit AppTest проходят начальную пустую сессию, настройки и обучение, прогноз/экспорт метрик, продолжение MLP, общий контроль, историю и новую UI-сессию с прежними версиями. Отдельно проверены оба предметных сценария и их прогнозы, некорректные слои, запрет старого прогноза при смене входа, адаптеры загрузок и параметры локального запуска. В сквозных AppTest файлы подаются через адаптер table_input/data_directory: нативный диалог выбора файла браузера AppTest не автоматизирует. Сервер отдельно проверяется по HTTP.

Streamlit и его обязательные зависимости добавлены в проверенный список requirements. Сам UI без браузерной автоматизации проверен через AppTest; ручная визуальная приёмка в настоящем браузере, Windows и чистое окружение остаются итерацией 9. Версии Python/библиотек сохранённых моделей по-прежнему проверяются строго; ради установки UI исходные numpy/pandas не обновлялись.

Руководство: ui-guide.md. Сервер слушает только loopback, сбор usage-статистики отключён. Операции синхронны; нет многопользовательского планировщика или облачной публикации.

Итог: `python -m pytest -q` — 61 passed, включая 55 предыдущих проверок и 6 UI-проверок. Тестовое окружение использовало /tmp/predictml-ui-deps и /tmp/predictml-iteration4-deps. Локальный запуск `python -m predictml ui` проверен на 127.0.0.1:18501: главная страница и /_stcore/health вернули HTTP 200. После проверки тестовый сервер остановлен. Для установки Streamlit из временного каталога launcher явно отключает developmentMode; тест закрепляет эту настройку вместе с loopback/headless/usageStats. `git diff --check` ошибок не обнаружил. Итерация 8 завершена; следующая — итоговая приёмка (9).
