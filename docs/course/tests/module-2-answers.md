## 2.2. Модели, обучение и оценка

1. **А** — Несогласованная размерность — ошибка модели, а не правило заполнения. Источник: презентация 2.2, слайд 2.

2. **Б** — Baseline использует среднее train: 300 / 3 = 100. Источник: презентация 2.2, слайд 3.

3. **Б** — Среднее baseline не зависит от ответов test. Источник: презентация 2.2, слайд 3.

4. **А** — LinearRegression обучается другим способом; длительность не доказывает сбой. Источник: презентация 2.2, слайд 4.

5. **Б** — Линейные слои без нелинейности сводятся к одному линейному преобразованию. Источник: презентация 2.2, слайд 5.

7. **Б** — Обнуление касается градиентов, а не обученных весов. Источник: презентация 2.2, слайд 7.

10. **А** — Программа восстанавливает лучший checkpoint, а не последнее или усреднённое состояние. Источник: презентация 2.2, слайд 9.

11. **В** — Счётчик обновляется при очередной validation-проверке. Источник: презентация 2.2, слайд 9.

12. **Б** — Test не участвует в выборе рекомендованного кандидата. Источник: презентация 2.2, слайд 11.

14. **А** — Test-ответы вправе менять оценку, но не обучение и выбор. Источник: презентация 2.2, слайд 13.

15. **В** — Проверка на синтетической зависимости не доказывает универсального превосходства. Источник: презентация 2.2, слайд 14.
