# Модуль 1. Тестовые вопросы

В каждом вопросе один правильный ответ из трёх.


## 1.1. Задачи машинного обучения и прогнозирования


1. В программе коэффициенты зависимости подбираются по примерам, а норматив расхода задан в справочнике. Где здесь обучение?

   А) В подборе коэффициентов по наблюдениям.

   Б) В умножении готового спроса на норматив.

   В) В вычитании известного остатка из потребности.


2. Что представляет собой y в обучении с учителем?

   А) Набор входных признаков.

   Б) Известное целевое значение обучающего примера.

   В) Набор параметров модели.


3. Какой вариант описывает регрессионную задачу?

   А) Определить, будет ли запись отменена.

   Б) Оценить количество записей в следующем месяце.

   В) Определить категорию услуги.


4. Для таблицы «услуга–месяц» выбирают признаки прогноза. Что необходимо определить сначала?

   А) Только период, на котором получилась наименьшая ошибка.

   Б) Все числовые столбцы, независимо от момента получения.

   В) Момент прогноза и какие значения известны к нему.


5. Спрос требуется оценить на три месяца вместо одного. Что меняется в постановке?

   А) Только имя выходного файла, если признаки те же.

   Б) Только число входных признаков, независимо от времени цели.

   В) Горизонт и смысл оцениваемого будущего результата.


6. Как разделить историю для проверки прогноза будущего спроса?

   А) Случайно распределить все месяцы между train и test.

   Б) Обучать на ранних периодах, оценивать на последующих.

   В) Обучать на последних месяцах, оценивать только на первых.


7. Какой пример является утечкой данных?

   А) Средние вычислены по train и применены к test.

   Б) Средние для нормализации вычислены по train, validation и test вместе.

   В) Спрос прошлого месяца использован для прогноза следующего.


8. Как трактовать результат модели, если целевая цена рассчитана экспертной формулой?

   А) Как рекомендацию, воспроизводящую заданное правило.

   Б) Как независимое наблюдение будущей рыночной цены.

   В) Как доказательство оптимальности цены для прибыли.


9. Какой признак допустим для прогноза спроса следующего месяца?

   А) Количество завершённых записей за предыдущий полный месяц.

   Б) Выручка, которая станет известна после прогнозируемого месяца.

   В) Фактическое количество записей за прогнозируемый месяц.


10. Из прогноза спроса требуется получить закупку. Какой маршрут согласован с разделением модели и правил?

   А) Норма → прогноз спроса из текущего остатка без истории.

   Б) Прогноз → закупка того же количества без учёта норм.

   В) Прогноз → расход по нормам → учёт запаса и остатка.


11. MLP сложнее baseline, но их нужно сравнить. Для чего сохраняют простой ориентир?

   А) Чтобы заменить им факты test при оценке неизвестных строк.

   Б) Чтобы выбрать сложность только по обучающей ошибке baseline.

   В) Чтобы проверить дополнительную пользу на тех же наблюдениях.


12. Какое описание задачи позволяет проверить доступность признаков и качество результата?

   А) Объект, цель, момент прогноза, доступные входы и оценка.

   Б) Цель, список всех колонок, библиотека, устройство и seed.

   В) Объект, цель, архитектура, время обучения и размер файла.


13. Для проверки будущего спроса случайно смешали ранние и поздние месяцы. В чём риск?

   А) Случайное разбиение гарантирует проверку на будущих периодах.

   Б) Любая случайность исчезает после нормировки признаков.

   В) Обучение может использовать периоды, будущие для оцениваемых условий.


14. Как правильно восстановить рекомендацию из базовой цены и предсказанного price_ratio?

   А) Базовая цена 2000, коэффициент 1.05: рекомендация 2001.05.

   Б) Базовая цена 2000, коэффициент 1.05: рекомендация 2100.

   В) Базовая цена 2000, коэффициент 1.05: рекомендация 2050.


15. Прогноз — 20 услуг, норма — 3 единицы материала, остаток — 10. Минимальный запас не требуется. Какова закупка без округления?

   А) 50 единиц.

   Б) 30 единиц.

   В) 60 единиц.


## 1.2. Методы прогнозирования и выбор модели


1. Выбираем семейство моделей до настройки. Что служит основной опорой?

   А) Только наименьшая ошибка на обучающей части.

   Б) Только минимальное время fit без требований к качеству.

   В) Структура данных и требования конкретной задачи.


2. Последний наблюдавшийся спрос равен 42, среднее истории — 38. Что выдаст правило ŷₜ = yₜ₋₁?

   А) 38.

   Б) 42.

   В) 40.


3. Что означает коэффициент линейной регрессии при прочих фиксированных признаках?

   А) Направление и величину линейного изменения прогноза.

   Б) Доказанное причинное влияние признака.

   В) Вероятность правильного прогноза для всей модели.


4. Какое соответствие методов и штрафов верно?

   А) Ridge и Lasso не используют штрафов.

   Б) Ridge — L1; Lasso — L2.

   В) Ridge — L2; Lasso — L1.


5. Дерево стало очень глубоким и почти точно описывает train. Какой риск проверить?

   А) Подстройку под частные особенности train и потерю обобщения.

   Б) Обязательную потерю всех нелинейных зависимостей.

   В) Автоматическое превращение дерева в среднее всех целей.


6. Для одной строки получены прогнозы нескольких деревьев Random Forest. Как формируется общий прогноз регрессии?

   А) Объединением, обычно усреднением, ответов деревьев.

   Б) Последовательной донастройкой деревьев на ошибке этой test-строки.

   В) Выбором дерева по известному ответу именно этой test-строки.


7. Чем последовательное обучение бустинга отличается от независимого набора деревьев?

   А) Каждое дерево обучается без учёта текущего ансамбля.

   Б) Новое дерево исправляет часть ошибок уже построенного ансамбля.

   В) Из всех деревьев оставляют одно по его ошибке train.


8. Какой принцип лежит в основе экспоненциального сглаживания?

   А) Все наблюдения обязательно имеют одинаковый вес.

   Б) Свежие наблюдения получают больший вес.

   В) Будущие наблюдения используются вместо прошлых.


9. Что обозначает компонент I в ARIMA?

   А) Инициализацию весов нейронной сети.

   Б) Кодирование идентификаторов категорий.

   В) Дифференцирование временного ряда.


10. Что получает MLP в табличной задаче?

   А) Готовые ответы тестовой выборки вместо признаков.

   Б) Только необработанную временную последовательность переменной длины.

   В) Заранее подготовленный вектор признаков.


11. В чём особенность RNN/LSTM по сравнению с обычной табличной MLP?

   А) Они всегда точнее линейной модели независимо от данных.

   Б) Они обрабатывают последовательности с учётом порядка шагов.

   В) Они не требуют обучения параметров.


12. С чего разумно начать при короткой истории и требовании объяснимости?

   А) С наиболее глубокой доступной нейронной сети.

   Б) С простого baseline и линейной модели.

   В) С выбора алгоритма исключительно по обучающей ошибке.


13. Спрос последних трёх месяцев: 8, 12, 16. Что дадут прошлое значение и среднее трёх?

   А) 16 и 12 соответственно.

   Б) 12 и 16 соответственно.

   В) Оба дадут 16.


14. На небольшом наборе MLP уступила линейной модели. Какой выбор обоснован?

   А) Сохранить простую модель, если она лучше по принятому критерию.

   Б) Удалить baseline, чтобы не снижать средний результат сравнения.

   В) Выбрать MLP, поскольку сложность гарантирует лучшее обобщение.


15. В ряду заметен повторяющийся календарный рисунок. Какой компонент временного метода учитывает его?

   А) Уровень без сезонных изменений.

   Б) Постоянное смещение линейной модели без календарных признаков.

   В) Сезонность.


## 1.3. Нейронные сети и оценка качества


1. У нейрона до активации x = [2, 3], w = [1, −1], b = 2. Чему равен z?

   А) 3.

   Б) −1.

   В) 1.


2. Пакет из 32 объектов с 7 признаками поступает в полносвязный слой с 16 выходами. Какова форма выхода?

   А) 7 × 16.

   Б) 16 × 7.

   В) 32 × 16.


3. Зачем между линейными слоями применяется ReLU?

   А) Чтобы добавить нелинейность преобразования.

   Б) Чтобы заменить обучение весов вычислением среднего.

   В) Чтобы гарантировать нулевую ошибку на test.


4. По какому числу определяется input_size универсальной MLP?

   А) По числу признаков после предобработки.

   Б) По максимальному количеству эпох.

   В) По числу строк всей исходной таблицы.


5. Что делает predict при применении уже обученной модели?

   А) Подбирает новые веса на каждой строке прогноза.

   Б) Выполняет прямой проход с сохранёнными параметрами.

   В) Добавляет тестовые цели к обучающей выборке.


6. Какие параметры масштабирования применяются к новым данным?

   А) Заново рассчитанные статистики каждой новой таблицы.

   Б) Статистики объединения train и фактического будущего.

   В) Сохранённые средние и стандартные отклонения train.


7. Какова корректная последовательность одного шага обучения PyTorch?

   А) Forward, optimizer.step, затем вычислить loss без backward.

   Б) Измерить test, заменить им train и применить predict.

   В) Обнулить градиенты, forward, loss, backward, optimizer.step.


8. Градиент loss по весу равен 2, вес равен 1, learning rate = 0.1. Каким станет вес после шага спуска?

   А) 0.8.

   Б) 0.98.

   В) 1.2.


9. Train содержит 400 строк и обрабатывается пакетами. Что означает завершение одной эпохи?

   А) Один полный проход по этим обучающим строкам.

   Б) Один проход по train, validation и test с обновлением весов.

   В) Одно обновление весов на первом пакете.


10. Какая часть данных используется для выбора лучшей эпохи?

   А) Test.

   Б) Validation.

   В) Новые данные, для которых фактические ответы ещё неизвестны.


11. Train-ошибка падает, validation растёт. Как интерпретировать такую динамику?

   А) Улучшение обобщения доказано снижением train.

   Б) Возможно переобучение при ухудшении обобщения.

   В) Эта динамика сама по себе доказывает нехватку эпох.


12. Сумма абсолютных ошибок равна 15, сумма абсолютных фактических значений — 150. Чему равна wMAPE?

   А) 10%.

   Б) 15%.

   В) 5%.


13. В новых данных среднее признака изменилось. Какие μ и σ применить к сохранённой MLP?

   А) Средние между статистиками train и новых строк.

   Б) Сохранённые μ_train и σ_train.

   В) Пересчитанные по новым данным μ_new и σ_new.


14. Архитектуру многократно выбирали по test, не выполняя на нём backward. Осталась ли оценка независимой?

   А) Да, если все архитектуры имели одинаковый seed.

   Б) Нет, test уже использован для выбора.

   В) Да, без backward информация test не используется.


15. При признаках переобучения какое решение согласовано с ролью validation?

   А) Продолжать до минимальной train-ошибки независимо от validation.

   Б) Перенести test в train и оставить прежнюю оценку независимой.

   В) Сохранить лучший checkpoint и рассмотреть регуляризацию или более простую модель.
