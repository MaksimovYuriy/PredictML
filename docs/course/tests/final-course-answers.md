# Итоговый тест. Ответы и пояснения
Преподавательская версия. Максимум 30 баллов.
1. **Б** — Регрессия оценивает числовую величину. Вероятность события относится к классификационной постановке, хотя сама записывается числом. Источник: Модуль 1, пособие §1.3; презентация 1.1, слайды 5.

2. **А** — Мартовская фактическая выручка ещё неизвестна в момент прогноза; февральская история и календарь могут быть доступны. Источник: Модуль 1, пособие §3.9; презентация 1.1, слайды 9.

3. **А** — Модель аппроксимирует происхождение своей цели; ошибка относительно формулы не измеряет рынок или причинность. Источник: Модуль 1, пособие §1.6; презентация 1.1, слайды 10.

4. **В** — Изменение равно коэффициенту при x₁, умноженному на изменение входа: 2×4=8. Это изменение прогноза, а не доказанный причинный эффект. Источник: Модуль 1, пособие §1.9; презентация 1.2, слайды 5.

5. **А** — В обзоре Ridge соответствует L2, Lasso — L1; Lasso может занулять часть коэффициентов. Источник: Модуль 1, пособие §1.4.2; презентация 1.2, слайды 6.

6. **В** — Последовательное исправление ошибок — идея бустинга. Выбор по ответу test был бы утечкой. Источник: Модуль 1, пособие §1.4.4; презентация 1.2, слайды 8, 9.

7. **Б** — До активации z=1−6+1=−4; ReLU возвращает max(0,−4)=0. Источник: Модуль 1, пособие §2.2; презентация 1.3, слайды 3, 5.

8. **А** — Количество строк пакета сохраняется; ширина выхода становится равной числу выходных нейронов. Источник: Модуль 1, пособие §2.3; презентация 1.3, слайды 4.

9. **В** — Dropout действует в режиме обучения; оценка требует eval. Пересчёт преобразований на validation создавал бы утечку. Источник: Модуль 1, пособие §2.7; презентация 1.3, слайды 7, 13.

10. **В** — 18/300×100%=6%. Это отношение сумм, а не обратное отношение или доля без перевода в проценты. Источник: Модуль 1, пособие §3.14; презентация 1.3, слайды 14.

11. **Б** — Цель не должна быть входным признаком ни одного кандидата: иначе задача получает готовый ответ. Источник: Модуль 2, пособие §2.1.4; презентация 2.1, слайды 7.

12. **А** — Неизвестная цель не заменяется предположением. Пропуск допустимого входа имеет отдельную политику преобразования. Источник: Модуль 2, пособие §2.1.5; презентация 2.1, слайды 8.

13. **Б** — Обучаемые преобразования являются частью модели; отсутствие backward на test не устраняет утечку через scaler. Источник: Модуль 2, пособие §2.1.6; презентация 2.1, слайды 9, 11.

14. **В** — Сохранённый конвейер использует handle_unknown=ignore. Допустимый вход не доказывает качества на новой категории. Источник: Модуль 2, пособие §2.1.6; презентация 2.1, слайды 12.

15. **А** — Ссылка на изменяемые тензоры не фиксирует старые веса. Копирование сохраняет checkpoint соответствующей проверки. Источник: Модуль 2, пособие §2.2.4; презентация 2.2, слайды 9.

16. **Б** — Выбор выполняется по validation MSE; test не меняет правило рекомендации и не задаёт автоматический ансамбль. Источник: Модуль 2, пособие §2.2.5; презентация 2.2, слайды 11.

17. **А** — Весам должны соответствовать тот же смысл, порядок и масштаб входов; одинаковая ширина не восстанавливает потерянное состояние. Источник: Модуль 2, пособие §2.3.5; презентация 2.3, слайды 10, 11.

18. **А** — Чистая потребность max(0,12+3−5)=10, округление вверх до кратного 6 даёт 12. Источник: Модуль 2, пособие §2.3.3; презентация 2.3, слайды 8.

19. **В** — Fine-tune фиксирует архитектуру и входное пространство; изменение архитектуры требует соответствующей операции нового обучения. Источник: Модуль 2, пособие §2.4.2; презентация 2.4, слайды 3, 4.

20. **Б** — Работа рядом с checkout может скрывать отсутствие ресурсов в wheel; это задача состава поставки, а не оптимизации модели. Источник: Модуль 2, пособие §2.4.6; презентация 2.4, слайды 13.

21. **Б** — Сначала согласуются единицы и строки. При линейном переводе валютной единицы MAE масштабируется тем же коэффициентом. Источник: Модуль 3, пособие §3.3.1; презентация 3.3, слайды 2, 3.

22. **В** — Linear обучается другим способом. Время само по себе не является критерием качества или признаком завершённости fit. Источник: Модуль 3, пособие §3.1.7; презентация 3.1, слайды 8.

23. **Б** — Ошибка требует фактического ответа; правдоподобие или сравнение числа с собой не заменяет оценку. Источник: Модуль 3, пособие §3.2.5; презентация 3.2, слайды 6.

24. **В** — Выбор по метрикам тоже использует ответы набора. Независимость не определяется только наличием градиентного шага. Источник: Модуль 3, пособие §3.1.10; презентация 3.1, слайды 11.

25. **Б** — Факты будущего относительно исходной границы не доступны рекурсивной процедуре и нужны только для последующей оценки. Источник: Модуль 3, пособие §3.2.8; презентация 3.2, слайды 8, 9.

26. **А** — Отрицательный R² означает результат хуже постоянного среднего фактов оценочного набора по квадратичному критерию. Это совместимо со снижением MAE относительно ещё более слабого родителя и не разрешает обучать модель на контроле. Источник: Модуль 3, пособие §3.3.7; презентация 3.3, слайды 3, 4.

27. **В** — Совместимость схемы не доказывает независимости. Отказ проверки не равен невозможности применять модель. Источник: Модуль 3, пособие §3.3.6; презентация 3.3, слайды 9, 10.

28. **Б** — Разделение seed разбиения и весов позволяет исследовать выбранный источник случайности без смешения причин. Источник: Модуль 3, пособие §3.3.4; презентация 3.3, слайды 7.

29. **В** — Происхождение целевой переменной ограничивает смысл результата; формула не доказывает причинный бизнес-эффект. Источник: Модуль 3, пособие §3.3.8; презентация 3.3, слайды 12.

30. **А** — Вывод описывает конкретные условия и наблюдаемое сравнение, не приписывая неподтверждённый механизм или универсальность. Источник: Модуль 3, пособие §3.3.9; презентация 3.3, слайды 13, 14.
