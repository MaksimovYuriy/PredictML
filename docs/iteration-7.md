# Итерация 7: переобучение, дообучение и сравнение версий

Добавлены updates.update_version и version_comparison.compare_versions, CLI retrain/fine-tune/compare-versions. Обновления работают для универсальных таблиц, demand-v2 и рекомендации цены; linear/baseline переобучаются с нуля, MLP может также продолжать с сохранённых весов.

Общая PyTorch-оптимизация принимает initial_state и загружает его до создания нового Adam. Предобработка при продолжении копируется без fit; структура сети и dropout берутся из родителя. Изменение цели/признаков при scratch-retrain таблицы создаёт новую модель без parent_id, при совместимой схеме родитель связывается через SQLite FK. Предыдущие файлы не меняются.

Новые обучения и обновления сохраняют состав наблюдений через provenance, продолжение наследует данные, повлиявшие на старые веса. Независимый контроль проверяется против всех сравниваемых версий. Отсутствующие сведения у старых версий не подменяются утверждением о независимости: сравнение отклоняется. Подробнее о консервативных ограничениях идентификации наблюдений — updates-contract.md.

Общий контроль не используется для выбора весов/настроек. Спрос оценивается в рекурсии на одинаковой истории, цена — как восстановление месячной рекомендации. Отчёты JSON/CSV/HTML/XLSX фиксируют версии, состав и условия сравнения; результаты и ошибки регистрируются как отдельные SQLite-запуски.

Проверены загрузка родительских весов, отсутствие refit предобработчика, сохранение архитектуры и файлов родителя, fresh-retrain без initial_state, новая нормировка при переобучении, lineage/new-model, отказы для линейного fine-tune и несовместимой архитектуры/схемы, наследование происхождения, пересечение/неизвестность контроля, отсутствие обучения при сравнении, обе операции в предметных сценариях и их общий будущий контроль. Прежние тесты сохранены.

Политика оптимизатора: fresh Adam с явно сохранёнными настройками; старые optimizer state/RNG-сессии не восстанавливаются. Новая версия не обязана превосходить прежнюю. Старые legacy-файлы и комплекты без provenance могут прогнозировать, но независимое сравнение непроверенного происхождения запрещено. Streamlit и окончательная приёмка остаются итерациями 8–9.
